     1→# Zerobet - Worklog
     2→
     3→## Project Overview
     4→Premium web application for gambling addiction recovery targeting the African francophone market. Built with Next.js 16, TypeScript, Tailwind CSS 4, shadcn/ui, Prisma (SQLite), Zustand, and z-ai-web-dev-sdk for AI Coach.
     5→
     6→## Design Philosophy (Superior to Competitor)
     7→- **Theme**: Deep dark (#0A0A0F) with animated starfield background
     8→- **Cards**: Glass morphism with backdrop blur over starfield
     9→- **Accent**: Red-orange gradient (#FF3B30 → #FF9500) for energy/CTAs
    10→- **Success**: Emerald green (#4ADE80) for progress
    11→- **Typography**: Poppins (titles) + Inter (body) - premium feel
    12→- **Mobile-first**: 430px container with responsive scaling
    13→- **Animations**: Framer Motion throughout (springs, slides, glow effects)
    14→- **i18n**: Full translation system (FR default, EN, ES, PT, AR, Wolof, Lingala)
    15→
    16→## Key Features (Beyond Competitor)
    17→1. Complete onboarding: Splash → Gender → Language → Welcome → Quiz(15Q) → Results → Symptoms → Carousel(8 slides) → Engagement → Paywall → Dashboard
    18→2. 4-tier plans: Free / Premium / Mentor / Psychologue with feature gating
    19→3. Parcours de Guérison: 13 ranks with unique aura effects per rank
    20→4. Atlas AI Coach with sliding tabs (Journal/Motivation/Progress/Crisis)
    21→5. Panic Button with 4-7-8 breathing + post-crisis journal
    22→6. Betting Blocker: 50+ sites with categories + strict mode
    23→7. Community: Testimonials + Forum + Mentors + Psychologists
    24→8. Admin Mode: 4-tap on logo for testing
    25→9. Privacy-focused: Data protection consent (no RGPD branding)
    26→10. Financial tracker with projections in FCFA

  1668→- The SoundInit's first-gesture listeners use capture phase (`true` 3rd arg) to fire before any other handlers; they auto-unregister after the first event. If the user never interacts (e.g. leaves the tab open in the background), the AudioContext stays uninitialized and all sound calls become no-ops — which is the correct silent-fail behavior.
  1669→- The TutorialTooltips measures target elements via `getBoundingClientRect()` and re-measures on resize/scroll. If a target element is removed from the DOM mid-tutorial (e.g. user navigates away), `targetRect` becomes null and the tooltip falls back to centered positioning — graceful degradation only; the tutorial will continue to advance via the Suivant button.
  1670→- The DailyInsights `analyzeJournalEmotions` uses the `emotion` field on JournalEntry plus `intensity` to decide between positive/tense/neutral messaging. Since MoodTracker writes journal entries with `intensity: 3` (fixed), mood-tracker entries contribute evenly to the emotion counts without skewing the intensity average.
  1671→- iOS Safari doesn't support the Vibration API at all — HapticsManager silently no-ops there. On iOS the user would need a native wrapper (Capacitor/Cordova) for true haptics; the audio sounds still work.
